# Kill Team 規則速查 — v1.8.1

v1.8 的資料拆分方向保留，但修正了 `file://` 直接開啟時 JSON `fetch()` 可能被瀏覽器阻擋的問題。

## 結構

```text
/
├─ index.html
├─ styles.css
├─ app.js
├─ data/
│  ├─ core_rules.js
│  ├─ weapon_rules.js
│  ├─ plague_marines.js
│  └─ angels_of_death.js
└─ assets/
   ├─ plague_marines/
   └─ angels_of_death/
```

資料仍然完全與 `index.html` 分離，只是由 JSON 改成獨立 JS 資料檔。

## 為什麼改成 .js
瀏覽器直接雙擊 `index.html` 時，網址是 `file://`。
Chrome / Safari 可能封鎖 JavaScript 對本機 JSON 的 `fetch()`，因此 v1.8 會顯示「規則資料載入失敗」。

Classic `<script src="data/xxx.js">` 不需要 fetch，因此：
- GitHub Pages 可以用
- PWA 可以用
- 電腦直接雙擊 index.html 也可以用

## v1.8.6 武器規則逐條對照
`weapon_rules.js` 已依官方簡中 Lite Rules 的中文術語重新整理，並以完整英文 Lite Rules 補足規則細節。

重要修正：
- Poison = `毒素`；Toxic = `劇毒`。
- Piercing Crits = `關鍵穿刺`，不是「穿刺暴擊」。
- Ceaseless = `無休`：選一種骰面結果，重擲所有該結果的攻擊骰；不是只重擲 1。
- Stun = `暈眩`：保留關鍵成功後使目標 APL -1，直到其下一次激活結束。
- Saturate = `集中`。
- Seek / Seek Light = `追蹤` / `追蹤輕型`。
- Punishing = `重擊`。
- Relentless = `毫不留情`。
- Limited = `有限 x`。

此外補齊 Lite Rules 中原本索引缺少的標準武器規則，現在可直接搜尋完整標準關鍵字。
